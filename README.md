# Heloisa Fit

Site para a personal trainer Heloisa, professora de educação física, com foco em levar a visitante até o contato pelo WhatsApp.

🔗 **Site no ar:** https://heloisa-fit.vercel.app

## Sobre o projeto

Projeto feito para cliente. É uma página única, responsiva e pensada primeiro para o celular, que apresenta os serviços, os planos e a profissional.

### Seções

- **Início:** chamada principal com destaque visual
- **Serviços:** treinos personalizados e avaliação física
- **Planos:** o que cada plano inclui e como começar
- **Sobre:** apresentação da Heloisa
- **Contato:** botão direto para conversa no WhatsApp

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Hospedagem na Vercel

## Como rodar localmente

É um site estático. Basta clonar o repositório e abrir o `index.html` no navegador:

```bash
git clone https://github.com/Rangel202/heloisa-fit.git
```

## Estrutura

```
index.html   conteúdo da página
style.css    estilos e responsividade
script.js    interações da página
img/         fotos usadas no site
```
